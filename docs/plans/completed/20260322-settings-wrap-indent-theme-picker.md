# Settings Modal: Wrap Long Strings, Save Indent, Inline Theme Selector

## Overview
- Extend the existing settings dialog with two new persisted settings: display-only long string wrapping and saved-file indentation.
- Keep the theme row as a simple inline selector inside the settings dialog, using left/right changes instead of a popup list.
- Keep saves explicit and deterministic: wrapping changes only the TUI display, while indentation changes the formatting used for pretty JSON outputs.
- Avoid introducing a generic settings framework; keep the implementation narrowly scoped to the three concrete settings now in use.

## Technical Details
- **settings shape**: persist the agreed settings as a real struct, for example:
  ```json
  {
    "theme": "mist",
    "wrap_long_strings": true,
    "save_indent": {
      "kind": "spaces",
      "size": 3
    }
  }
  ```
  For tabs mode, `kind` is `"tabs"` and `size` is ignored or normalized away.
- **theme behavior**: `Theme` stays inline in the settings dialog and cycles through built-in plus external themes directly with `left/right`, `h/l`, or `enter`.
- **wrap behavior**: wrapping is TUI-only and applies only to displayed string scalar values. It must not change the underlying document, clipboard string contents, or saved output bytes.
- **save-indent behavior**: the selected indent profile should drive all pretty JSON outputs emitted by the editor, including file saves, `:print`, and pretty clipboard actions. Compact JSON output remains unchanged.
- **settings file formatting**: `settings.json` itself should remain a stable internal config file and should not reuse the document save-indent preference.
- **state model**: `Theme` and `Long strings` should preview immediately in-session, while `Save indent` should update the in-memory setting used by later save/export actions without rewriting any file until the user explicitly saves settings.
- **rendering risk**: the current viewport logic assumes one logical row equals one visual line. Wrapped strings require explicit visual-line accounting so long values do not break scrolling or hide the selected row.
- **scope guardrails**: do not add a popup or filterable theme picker, generic settings sections, or formatting-preservation logic as part of this change.
